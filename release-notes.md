L8Play 0.2.1 makes console mode work better with the games you launch, and gives your saves more ways in and out.

- **Games that need administrator rights** now start through the Windows prompt instead of failing silently.
- **Console mode steps aside while you play**: L8Play minimizes when a game starts and comes back, full screen, when you quit it. This also frees the GPU for the game.
- **Start in console mode** (Settings › General, or the console's own settings): opens console mode as soon as L8Play starts, also when Windows launches it at sign-in.
- **Save Manager › Actions** gathers Create snapshot, Import saves and Export all saves in one menu.
- **Export all saves** writes every snapshot this PC holds into one zip, laid out like the Drive folder. It includes saves that were never uploaded.
- **Search this PC for saves** (Import saves › Search this PC): finds the leftover saves of games that are no longer installed, using the Ludusavi game database. You review the list before anything is copied.
- **Install or link a saves-only game**: its page offers to open a store search (Steam, Epic Games, GOG, Xbox) or to choose the game's executable and join the saves to it.
- **Sync conflicts are explained**: a banner says what a conflict is and what to do, and each notice can be hidden and shown again. Both saves are always kept.
- The dashboard keeps "Recent backups" visible on narrow windows.

Update from inside the app: Settings › Updates.
