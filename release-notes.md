L8Play 0.2.0 brings in the saves you backed up by hand, even for games that are no longer installed.

- **Import existing saves** (Add a game › Import saves only, or Save Manager › Import saves): choose the folder that holds your old backups, one sub-folder per game. L8Play finds each game, lets you check titles and snapshot names, and converts every backup into a regular verified snapshot. Your original files are never changed.
- Sub-folders such as "after ending A" or "before final choice" become separate named snapshots. Logs, crash dumps and screenshots are left out.
- Imported games appear in My Games as "Saves only", with their artwork, and get their own "Saves only" filter. When you install the game later, its page offers to join the saves to it.
- Restoring an imported snapshot asks where its files go (suggested from the backup's own note or the game's save folders). Files are copied over that folder, nothing in it is deleted, and replaced files are kept in a safety copy first.
- A long import can keep running in the background: a small card shows its progress and brings the window back.
- Leaving console mode now asks for confirmation.
- The Updates section of Settings shows the same orange dot as the Settings button when an update is waiting.
- Layouts adapt to narrow windows: the Save Manager details open as a slide-over, and the dashboard, game pages and Settings stack their columns when space runs out.

Update from inside the app: Settings › Updates.
